Developed an AI-powered empathic chat application designed to provide emotionally aware and supportive conversations. The system leverages a multi-agent architecture to analyze user inputs and generate contextually relevant, empathetic responses. Built and deployed using modern web technologies on Vercel, the project focuses on enhancing user interaction through emotion-sensitive AI communication.

URL: https://tara-s-empathic-chat.vercel.app/
